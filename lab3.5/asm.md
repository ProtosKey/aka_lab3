# Построчное объяснение main.s

## Заголовок

```asm
.text
.org 0x100
```

`.text` — начало секции кода. `.org 0x100` — разместить секцию начиная с адреса 0x100.  
Без этого бандлы выросли бы до адреса 0x7E и перекрыли IO-порт 0x80 → «instruction in memory corrupted».

---

## _start

```asm
addi s4, zero, 0x80  / addi s5, zero, 0x84  / nop / nop
```
Загружаем адреса портов в S-регистры один раз на всё время работы:  
`s4 = 0x80` (читать X), `s5 = 0x84` (писать Y). Оба независимы → параллельно.

```asm
addi s6, zero, 3  / addi s7, zero, 2  / nop / nop
```
Коэффициенты фильтра: `s6 = 3` (для X[i]), `s7 = 2` (для X[i−1]). Тоже параллельно.

```asm
addi sp, zero, 0x800  / nop / nop / jal ra, run_filter
```
Инициализируем стек: `sp = 0x800`. В CTRL — вызов `run_filter`. `jal` записывает в `ra` адрес следующего бандла (адрес `halt`).

```asm
nop / nop / nop / halt
```
Сюда вернётся управление из `run_filter`. Останавливаем процессор.

---

## run_filter

Отвечает за: прочитать N, проверить, запустить N итераций.

```asm
addi sp, sp, -4  / nop / nop / nop
```
Выделяем 4 байта на стеке (одно слово) для сохранения `ra`.

```asm
nop / nop / sw ra, 0(sp) / nop
```
Сохраняем адрес возврата в `_start` на стек. Нужно: дальше будет `jal ra, compute_y`, который перезапишет `ra`.

```asm
nop / nop / lw s1, 0(s4) / nop
```
Читаем N из входного порта (адрес в `s4 = 0x80`). Результат в `s1`.

```asm
addi s2, zero, 0  / addi s3, zero, 0  / nop / blt s1, zero, rf_error
```
Инициализируем историю: `s2 = X[i−1] = 0`, `s3 = X[i−2] = 0`.  
Одновременно в CTRL: если N < 0 → прыжок в `rf_error`. CTRL читает `s1` до записей ALU — это безопасно, `s1` не меняется в этом бандле.

```asm
nop / nop / nop / beqz s1, rf_end
```
Если N = 0 — пропускаем цикл, идём на выход. Предотвращает вход в цикл с нулевым счётчиком.

---

## rf_loop

```asm
addi s1, s1, -1  / nop / nop / jal ra, compute_y
```
Декремент счётчика (`s1--`) и вызов `compute_y` — в одном бандле.  
`jal` читает только `pc`, не `s1` — конфликта нет. К началу `compute_y` `s1` уже уменьшен.

```asm
nop / nop / nop / bnez s1, rf_loop
```
Вернулись из `compute_y`. Проверяем: если ещё остались итерации — назад в `rf_loop`.  
`s1` уже уменьшен (записан в предыдущем бандле), так что проверка корректна.

---

## rf_end

```asm
nop / nop / lw ra, 0(sp) / nop
```
Восстанавливаем `ra` со стека (адрес `halt` в `_start`).

```asm
addi sp, sp, 4  / nop / nop / jr ra
```
Освобождаем стековый фрейм и возвращаемся в `_start`.

---

## rf_error

Вызывается если N < 0. Пишет −1 в выходной порт как сигнал ошибки.

```asm
addi t0, zero, -1  / nop / nop / nop
```
`t0 = −1`.

```asm
nop / nop / sw t0, 0(s5) / nop
```
Записываем −1 в порт 0x84.

```asm
nop / nop / lw ra, 0(sp) / nop
```
Восстанавливаем `ra`.

```asm
addi sp, sp, 4  / nop / nop / jr ra
```
Освобождаем фрейм, возвращаемся.

---

## compute_y

Вычисляет Y[i] = 3·X[i] + 2·X[i−1] + X[i−2], обновляет историю, пишет результат.  
Листовая процедура — не вызывает ничего, стековый фрейм не нужен.

```asm
nop  / mul t2, s7, s2  / lw t0, 0(s4)  / nop
```
**Параллельно:**  
— ALU2: `t2 = 2 · s2` = `2 · X[i−1]`  
— MEM: `t0 = X[i]` — читаем очередной элемент из порта 0x80  
Два независимых действия → оба в одном бандле.

```asm
mul t1, s6, t0  / add t3, t2, s3  / nop / nop
```
**Параллельно:**  
— ALU1: `t1 = 3 · t0` = `3 · X[i]` (использует только что загруженный `t0`)  
— ALU2: `t3 = t2 + s3` = `2·X[i−1] + X[i−2]` (использует `t2` из предыдущего бандла)  
`t1` и `t3` не зависят друг от друга → параллельно.

```asm
add t1, t1, t3  / nop / nop / nop
```
`t1 = t1 + t3` = `3·X[i] + 2·X[i−1] + X[i−2]` = Y[i].  
Отдельный бандл обязателен: `t1` и `t3` записались в предыдущем бандле, прочитать их раньше нельзя (RAW).

```asm
mv s3, s2  / mv s2, t0  / sw t1, 0(s5)  / jr ra
```
**Все 4 слота заняты — 100% утилизация:**  
— ALU1: `s3 = s2` — сдвигаем историю: старый X[i−1] становится X[i−2]  
— ALU2: `s2 = t0` — новый X[i] становится X[i−1] для следующей итерации  
— MEM: записываем Y[i] в порт 0x84  
— CTRL: возврат из процедуры  

Сдвиг истории безопасен: `s2` и `t0` **читаются** в начале такта, **записываются** в конце.  
`s3` получит старое `s2`, `s2` получит `t0` — обмен без временного регистра.
